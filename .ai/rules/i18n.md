# Client-facing text

Everything a client receives is translated with `tuttle/i18n.py`: invoice and timesheet templates, invoice and reminder emails, e-invoice free text. The app's own UI is English only for now (#570).

Applies to `templates/**`, `tuttle/rendering.py`, `tuttle/einvoice.py`, `tuttle/invoicing.py` and any new client-facing text.

- Write the English text inline: `_("Due Date")` in Python, `{{ _("Due Date") }}` in templates.
- One message per whole sentence, with named placeholders: `_("Invoice {number}", number=n)`. Never stitch a sentence together from pieces, and never pass an f-string to `_()` (ruff `INT` catches that).
- Quantities: `ngettext("hour", "hours", n)`.
- Produce a document inside `with use_language(lang):`. The language is the client's, else the app-wide default: `_document_language()` in `tuttle/app/invoicing/intent.py`.
- Format dates and amounts with Babel and `i18n.babel_locale()`, not `strftime`.
- In a module that imports `_`, don't use `_` as a throwaway variable.
- After adding or changing text, run `just i18n` and translate the new empty `msgstr` entries in `tuttle/locales/*/LC_MESSAGES/messages.po`. Untranslated entries fall back to English.
- New language: `just i18n-add <code>`, then translate. A language is offered as soon as its catalog exists.
